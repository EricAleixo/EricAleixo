## About Me

I'm a Computer Science student (Licenciatura) at **UFPB, Campus IV**, currently building my career as a software developer.

I'm deeply interested in web development, backend, frontend, systems architecture, APIs, infrastructure, and DevOps. I learn best by building real projects and solving practical problems, and my goal is to grow from someone who "just makes it work" into a developer who understands architecture, scalability, security, maintainability, and code quality.

I'm mainly deepening my knowledge in **TypeScript, React, Next.js, Node.js, NestJS, Java, Spring Boot, PostgreSQL, Docker, REST APIs, JWT/authentication, software architecture, Linux, and cloud infrastructure**.

I also have experience/contact with Ruby on Rails, Python/FastAPI, React Native/Expo, Prisma, Drizzle ORM, Tailwind CSS, Maven, JPA/Hibernate, Nginx, AWS, Cloudflare, n8n, and the WhatsApp Cloud API / Meta APIs.
